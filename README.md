# Online Shoppers Purchasing Intention — AIE231

Predict whether an online shopping session ends in a purchase (Revenue). Because the target is imbalanced, report macro-F1, purchase-class recall and ROC-AUC as well as accuracy.

Dataset: UCI Online Shoppers Purchasing Intention, ID 468: https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention. Raw data is downloaded locally and is not committed.

## Setup
Use Python 3.11 or 3.12 (TensorFlow may not support the newest Python release).

    python -m venv .venv
    # Windows: .venv\Scripts\activate
    # macOS/Linux: source .venv/bin/activate
    python -m pip install --upgrade pip
    pip install -r requirements.txt

## Run from repository root

    python data/download_data.py
    python -m src.data
    python -m src.train
    python -m src.evaluate

The data pipeline creates stratified 70/15/15 splits. Scaler and encoder are fitted on training data only. Training compares majority and logistic-regression baselines with three MLP variants; validation macro-F1 chooses the neural architecture. Test data is used only by the final evaluation step.

## Raw-input inference

    python -m src.predict path/to/new_sessions.csv

The CSV must contain the original input feature columns and must not contain Revenue.

## Structure
- data/download_data.py: fetch dataset from UCI
- src/data.py: cleaning, splitting, preprocessing and class weights
- src/models.py: baselines and three MLP architectures
- src/train.py: model training, early stopping and experiment log
- src/evaluate.py: test metrics, confusion matrix, ROC and misclassified samples
- src/predict.py: raw-row prediction with confidence
- configs/: project configuration
- experiments/: generated logs, curves and evaluation outputs
- models/: saved models and preprocessing objects

Generated data, models and result files are excluded from Git. Numerical results must be generated by running the pipeline; none are fabricated in this README.

Remaining full-course requirements beyond this initial Week 9 pipeline include systematic hyperparameter studies, four controlled ablations, three-seed final results, hand-checked parameter counts, a GradientTape training step, detailed error categorization, report PDF and presentation.
